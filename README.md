# Little Big Hearts · Character Growth Tracker

A cloud-based character assessment system for Little Big Hearts International & Private Preschool, Kulai, Johor.

## Features
- Daily observation log with AI writing helper
- Weekly summaries and monthly assessments
- Admin and teacher accounts
- Printable weekly / monthly / yearly reports
- Student award cards (printable)
- Works on phone, tablet and computer
- Data stored permanently in Firebase cloud

## How to use
Open the app at the GitHub Pages link. Log in with your admin or teacher credentials.

## Admin
Default admin username: `admin`
Password: set during first Firebase setup.

## Built with
- Vanilla HTML/CSS/JS (no build step)
- Google Firebase Firestore (cloud database)
- Anthropic Claude API (AI writing helper)
