Little Big Hearts — First-Time Setup

This app uses Google Firebase (free) to store all data permanently in the cloud. Complete this setup once — it takes about 5 minutes.

1

Create a Firebase project

Go to console.firebase.google.com → sign in with Google → Add project → name it (e.g. lbh-tracker) → disable Analytics → Create project.

2

Enable Firestore & set security rules

In your project: Build → Firestore Database → Create database → Production mode. Pick region asia-southeast1. Click Enable.

Then go to Firestore → Rules tab, replace all text with the rules below, click Publish:

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /{document=**} { allow read, write: if true; } } }
3

Get your Firebase config & paste it below

In Firebase: Project Settings (gear ⚙ top-left) → scroll to Your apps → click </> Web → register with any nickname → copy the firebaseConfig object.

4
